# Upload with GitHub Desktop

1. Extract the ZIP.
2. Open GitHub Desktop.
3. Choose **File → Add local repository**.
4. Select the extracted `luci-theme-x1wrt` folder.
5. If GitHub Desktop asks to create a repository, allow it.
6. Commit all files.
7. Click **Publish repository**.
8. Open the repository on GitHub.
9. Go to **Actions**.
10. Run **Build X1Wrt OpenWrt packages**.

For your current OpenWrt 24.10 router, use the `.ipk` artifact.
For OpenWrt 25.12+ or snapshots, use the `.apk` artifact.
